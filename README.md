# 🚀 Mini Proyek C# Dasar (Console Applications)

Repository ini berisi kumpulan program-program sederhana yang saya buat untuk mengasah logika dan memahami sintaks dasar bahasa pemrograman **C#** murni.

Semua program di sini berbasis teks (*Console-based*) dan fokus pada penerapan logika pemrograman seperti percabangan, perulangan, variabel, dan struktur data dasar.

---

## 🎮 Daftar Program yang Tersedia

Berikut adalah beberapa mini-proyek yang sudah berhasil saya buat:

* **🧮 Kalkulator Sederhana (`Kalkulator/`)**
  Aplikasi kalkulator berbasis konsol untuk melakukan operasi matematika dasar (penjumlahan, pengurangan, perkalian, dan pembagian). Fokus belajar: *kondisional (if-else/switch case) dan input/output.*
  
* **🌡️ Konversi Suhu (`KonversiSuhu/`)**
  Aplikasi untuk mengubah nilai suhu antar skala, yaitu dari Celsius ke Fahrenheit. Fokus belajar: *penerapan rumus matematika pada kode, tipe data float/double, dan manipulasi input angka.*

* **🎲 Game Tebak Angka (`TebakAngka/`)**
  Game interaktif di mana komputer mengacak angka, dan pemain harus menebaknya berdasarkan petunjuk "terlalu besar" atau "terlalu kecil". Fokus belajar: *operasi logika, fungsi Random, dan pembatasan nyawa/kesempatan.*

* **📝 To-Do List App (`TodoList/`)**
  Aplikasi pencatat tugas sederhana untuk menambah, melihat, dan menghapus daftar pekerjaan harian. Fokus belajar: *manipulasi List/Array dan perulangan (loops).*

---

## 🛠️ Persyaratan Sistem

Untuk menjalankan kode di repository ini, Anda hanya memerlukan:
* **.NET SDK** (Versi 8.0 atau yang terbaru)
* Editor kode seperti **Visual Studio** atau **VS Code**

---

## 💻 Cara Menjalankan Program

1. **Clone repository ini:**
   ```bash
   git clone https://github.com
   ```
2. **Masuk ke folder program yang ingin dijalankan (misal: TebakAngka):**
   ```bash
   cd nama-repo-anda/TebakAngka
   ```
3. **Jalankan programnya:**
   ```bash
   dotnet run
   ```
